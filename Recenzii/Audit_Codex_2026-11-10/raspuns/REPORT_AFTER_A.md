## B: checked and found correct / bounded conclusions

- g2_preview, td_audit, tech4_analysis and tb_part1_g2 fit their StandardScaler only inside training pipelines. Held-out masks are by run/family, not randomly split overlapping triplets. Overlap within a training run is not test contamination. GBDT hyperparameters are fixed in these scripts; no test-fitted scaling or explicit test-driven tuning was found.
- lm_forever_g2 and lm_d3_competitors hold out run names within each configuration; sni_analysis separately holds out runs and tasks. Task holdout still shares training trajectories, so it is weaker than independent-run transfer. td_audit's cross-configuration test is distinct from its leave-seed-out test.
- T-B excludes rate_ce_* and rate_Disp_* and uses rate features rather than C6 endpoint summaries. C10c/p/h are shared-probe competitors, not literal copies of D3: target-label loss, target probability and entropy changes versus full-distribution distance. Their shared measurement source limits an interpretation as independent cheap optimizer telemetry. LM L1, the near duplicate, is explicitly excluded from the verdict.
- T-A paired t intervals, ±0.02 margin, superiority rule and E1/E2 definitions agree with the Romanian preregistration. T-B's 6/8 threshold at noise 0.3, strict dose monotonicity and gate blocking H1 agree. SuperNI's mean R² in both schemes and paired relative-loss ±5% interval agree. rep_verdict applies the superseding version-3 common-adapter pairing and strict >2/<−2 rules correctly; stage 2 is optional and descriptive.
- Port inspection: 24-step calibration; thresholds 1,2,4,7,15,30,60,90,120 times the day; fresh optimizer/scheduler per phase; EMA coefficient .05; beta clipped .5–3; replay excluded from tau; reference moved after replay; task-start regularization anchor retained. Beta remains based on true tau in the clock-swap port. Continuous data stream, precision, replay-memory and training-duration changes are declared. Exact fidelity to the absent upstream implementation is unverified.
- Clock variant changes the replay counter and adds logging; mu still uses delta_t. However it counts lr times stale m on skipped optimizer updates; this is acknowledged by its post hoc zero-update diagnostic. A zero update alone does not prove GradScaler skip (warmup zero LR also exists). Hard-coded beta1=.9 and first-group LR limit portability.
- Synthetic agent uses explicit AdamW moments and no future gradient in its current update; D1 is algebraically tied to that update, not independently generated latent experience. D3 and competitors share probe evaluations. This can make reconstruction easy without statistical train/test leakage; conclusions must remain implementation-specific.
- Post hoc memory summary reconstructs memory sampling with seed*10+4, excludes task 9 and labels t intervals descriptive. Only tau/7301 validates all facts; the other cells are memory-only CPU rescoring. Noise summary separates greedy from sampled SD; three sampled evaluations per cell cannot establish a population noise bound. Tie diagnostic's supplied output can be checked, but raw-logit provenance cannot be certified without reproducing the absent model/software stack (output_scores may be processed generation scores).

## Limitations so far

No full training or generation rerun; no upstream code or model downloads permitted. Historical versions not preserved cannot be audited as if the present source produced them. Static correctness checks are not proof of exhaustive absence of bugs. Independent findings were written before reading any earlier reviews; those reviews remain unread.
